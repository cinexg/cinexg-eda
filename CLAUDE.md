## Quick orientation

`statlens` (renamed from `cinexg-eda`) is a small Python EDA package (`statlens/`) with
a CLI (`statlens.cli`), a pytest suite covering the analyzer/visualization/LLM/CLI
layers, and a manual smoke script at the repo root (`test.py`).

## Working in this repo

- **Pandas cannot import via plain Windows Python here** — Smart App Control (confirmed
  enforced on this machine) blocks its native DLLs regardless of Python version. The
  working dev environment is a venv at `.venv/` created inside WSL (Ubuntu), not Windows
  Python. Run commands via `wsl -d Ubuntu -- bash -c 'cd "/mnt/e/cinexg EDA" && ./.venv/bin/python ...'`.
  See AGENTS.md's "Running things" section for the full story and exact commands
  (pytest, ruff, the CLI). GitHub Actions CI (`ubuntu-latest`) is unaffected by any of
  this.
- GitHub repo is now `gauravxsuvo/Statlens` (confirmed; `pyproject.toml` and the README
  CI badge point at it).
- The package was previously published to PyPI as `cinexg-eda`. `statlens` is the
  actively developed name going forward; what happens to the old PyPI listing (left as
  is vs. deleted) is still an open decision the user makes outside this repo — deleting
  frees the name for anyone, including a bad actor, to re-register, so it isn't risk-free.
- `google-generativeai` (used for the optional AI executive summary) is a fully
  deprecated Google package — discovered via a `FutureWarning` during test runs, not yet
  migrated to its successor `google-genai`. See AGENTS.md's "Known inconsistencies".
- `.gitignore` covers `test.py`'s byproducts (`test_dataset.csv`,
  `my_first_eda_report.html`) and `report()`'s `eda_assets/` output directory. Anything
  else generated by a manual CLI run (custom `--output`/`--json` paths) is not
  automatically ignored — check `git status` after running it.
